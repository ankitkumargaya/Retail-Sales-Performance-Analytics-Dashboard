## 📥 How to Use the Dashboard

### Opening the Dashboard
1. Download the `.pbix` file from this folder  
2. Open Microsoft Power BI Desktop  
3. Click "Open" and select the `.pbix` file  
4. Wait for data to load (first load may take 30-60 seconds)  

### Interacting with Visuals
1. **Apply Filters:** Use slicers on the left to filter data  
2. **Drill-Down:** Click on data points to explore deeper  
3. **Change Dates:** Use date picker to select time periods  
4. **Export Data:** Right-click visualizations → "Export data"  

### Customizing Views
1. **Modify Filters:** Click "Edit" to add/remove filter fields  
2. **Change Date Range:** Drag slider or type specific dates  
3. **Toggle Visibility:** Click legend items to show/hide series

## ❌ Troubleshooting

### Dashboard Won't Open
- **Solution:** Ensure Power BI Desktop is up to date  
- **Action:** Update via Microsoft Store or download latest version  

### Data Not Refreshing
- **Solution:** Check data source connection  
- **Action:** Verify data files are accessible and not locked  

### Slow Performance
- **Solution:** Large datasets or complex queries  
- **Action:** Apply filters to reduce data volume, close other applications  

### Missing Data
- **Solution:** Source files may be outdated  
- **Action:** Verify data files contain latest information, refresh manually
